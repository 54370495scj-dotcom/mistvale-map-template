# 素材来源与安全边界

整理日期：2026-11-11。

## 来源

- 参考已有互动地图项目第 45 个保存版本的交互模式：区域切换、地图/列表筛选、点位详情、路线联动与本地进度提示。
- 所有交付代码重新编写，没有复制原项目源码文件或其样式。
- `assets/mistvale.svg` 与 `assets/starshore.svg` 是本次绘制的原创矢量示意图。地形、树木和等高线由基础路径组成，没有外部图片或字体。
- 两个区域、16 个点位、2 条路线、所有名称、坐标和文字都是虚构示例。
- 界面符号使用普通 Unicode 字符，字体使用访问者系统字体；不打包第三方字体。
- 三张截图仅展示本模板。所有测试进度均为临时生成的演示记录，没有导入原站浏览器进度。

## 明确排除

没有游戏截图、地图瓦片、攻略文章、真实点位数据、存档、账号信息、联系方式、密钥、令牌、环境变量文件、原 Git 对象或历史、原远程地址、网站身份和部署配置。

没有自动部署、推送或公开分享脚本。`package.json` 的 `private: true` 可防止误操作 npm 发布，但不能代替 GitHub、网站或其他平台的访问控制。

## 本地数据

应用只读写一个专用的浏览器本地存储键。进度只含本模板点位 ID 的 `completed` 与 `favorites` 数组，导出时附加导出时间。没有用户姓名或账号字段。

导入最多 100,000 字节。先检查 JSON、版本号、数组与点位 ID，再确认覆盖；无效文件不替换现有记录。未知的顶层字段不会进入应用状态。读取损坏进度时不会把未知当成已确认的空记录，也不会自动覆盖。

清空只影响当前模板的全部区域记录，先展示确认。这个操作无法在应用内撤销，需要提前导出备份。

## 静态保护

- 没有网络请求函数、远程脚本、远程 CSS、分析统计或第三方运行依赖。
- 动态文字用 `textContent` 写入，没有 `innerHTML`、`eval` 或动态函数构造。
- CSP 禁止网络连接、插件对象、表单提交与外部基础地址。
- SVG 无脚本、外链图像、事件属性或嵌入 HTML。
- 本机启动服务只监听 `127.0.0.1`。
- 发出文件前检查文件白名单、常见凭据签名、原项目标识、路径和 Git 新历史。

这些是有边界的静态与功能检查，不是渗透测试，也不能证明不存在所有未知风险。新增素材、远程接口、登录或编辑功能后，应重新检查。

从空仓库建立独立的初始提交，只包含本模板文件。使用中性示例作者信息，不含用户身份。交付的 bundle 无原项目历史、远程配置、部署凭据或浏览器存储。

没有选择对外许可证；见 `LICENSE-STATUS.md`。没有修改或重新发布原网站。
